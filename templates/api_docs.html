Rendez-vous
GET /api/v1/appointments Lister les rendez-vous ?date=2026-06-10
Exemple de réponse
{
  "ok": true,
  "count": 1,
  "appointments": [
    { "id": 5, "contact_id": 1, "contact_name": "Ahmed Benchekroun",
      "date": "2026-06-10", "time_slot": "09:30",
      "title": "Consultation de suivi", "notes": "" }
  ]
}
POST /appointments/book Réserver un créneau
Corps de la requête (JSON)
{
  "contact_id": 1,
  "date":       "2026-06-15",
  "time_slot":  "10:00",
  "title":      "Consultation",
  "notes":      ""
}
POST /appointments/cancel/{id} Annuler un rendez-vous
Étiquettes
GET /api/v1/labels Lister toutes les étiquettes avec compteurs
POST /api/v1/contacts/{id}/labels Assigner des étiquettes à un contact
Corps de la requête (JSON)
{ "label_ids": [1, 3, 7] }
Exemples cURL
Lister les contacts
curl -b cookies.txt {{ base_url }}api/v1/contacts
Créer un contact
curl -b cookies.txt -X POST {{ base_url }}api/v1/contacts \
  -H "Content-Type: application/json" \
  -d '{"name":"Test User","email":"test@example.com","phone":"+212600000000"}'
Se connecter (obtenir cookie)
curl -c cookies.txt -X POST {{ base_url }} \
  -d "username=admin&password=admin123"
